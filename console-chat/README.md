# 💬 Console Gemini ChatПростое консольное чат-приложение на чистом JavaScript (Node.js) для общения с языковой моделью **Google Gemini** без сторонних npm-пакетов.---## 📁 Структура проекта `console-chat/`- **[`chat.js`](./chat.js)** — Точка входа в консольное приложение. Организует интерактивный ввод через `readline` и отправку сообщений в модель.- **[`geminiAdapter.js`](./geminiAdapter.js)** — Адаптер к Google Gemini API (скрывает все детали HTTP-запросов, заголовков и формата сообщений).- **[`openCodeAdapter.js`](./openCodeAdapter.js)** — Модуль обратной совместимости (алиас к `geminiAdapter.js`).- **[`package.json`](./package.json)** — Конфигурация запуска скриптов.- **[`docs/c4-model/`](./docs/c4-model/)** — **Все 4 уровня C4-диаграмм в формате PlantUML (`.puml`)**:  - [`level1-context.puml`](./docs/c4-model/level1-context.puml) — System Context (Уровень 1)  - [`level2-container.puml`](./docs/c4-model/level2-container.puml) — Containers (Уровень 2)  - [`level3-component.puml`](./docs/c4-model/level3-component.puml) — Components (Уровень 3)  - [`level4-code.puml`](./docs/c4-model/level4-code.puml) — Code / Sequence execution (Уровень 4)- **[`docs/architecture.md`](./docs/architecture.md)** — Сводный markdown-документ со схемами.---## 🚀 Запуск приложения### 1. Из директории `console-chat/`:```bashcd console-chatnode chat.js# илиnpm start```### 2. Из корня репозитория:```bashnode console-chat/chat.js# илиnpm run chat```---## 🔑 Настройка API-ключаКлюч автоматически загружается функцией `loadEnv()` из следующих мест:1. `02-lesson/frontend/.env` (переменные `OPENCODE_API_KEY`, `VITE_OPENCODE_API_KEY`, `GEMINI_API_KEY`)2. Корневой файл `.env` проекта3. Локальный `.env` внутри папки `console-chat/`4. Системные переменные окружения (`process.env.GEMINI_API_KEY`)---## 📊 C4 Архитектурные диаграммы (.puml)Схемы всех 4 уровней по стандарту C4-PlantUML:- 📌 [Level 1: System Context](./docs/c4-model/level1-context.puml)- 📌 [Level 2: Containers](./docs/c4-model/level2-container.puml)- 📌 [Level 3: Components](./docs/c4-model/level3-component.puml)- 📌 [Level 4: Code Sequence](./docs/c4-model/level4-code.puml)
