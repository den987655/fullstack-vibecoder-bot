# 💬 Console Gemini ChatПростое консольное чат-приложение на чистом JavaScript (Node.js) для общения с языковой моделью **Google Gemini** без сторонних npm-пакетов.---## 📁 Структура проекта `console-chat/`- **[`chat.js`](./chat.js)** — Точка входа в консольное приложение. Организует интерактивный ввод через `readline` и отправку сообщений в модель.- **[`geminiAdapter.js`](./geminiAdapter.js)** — Адаптер к Google Gemini API (скрывает все детали HTTP-запросов, заголовков и формата сообщений).- **[`openCodeAdapter.js`](./openCodeAdapter.js)** — Модуль обратной совместимости (алиас к `geminiAdapter.js`).- **[`package.json`](./package.json)** — Конфигурация запуска скриптов.- **[`docs/architecture.md`](./docs/architecture.md)** — **4 уровня архитектурных диаграмм** (System Context, Runtime & Containers, Components, Code Execution Sequence).---## 🚀 Запуск приложения### 1. Из директории `console-chat/`:```bashcd console-chatnode chat.js# илиnpm start```### 2. Из корня репозитория:```bashnode console-chat/chat.js# илиnpm run chat```---## 🔑 Настройка API-ключаКлюч автоматически загружается функцией `loadEnv()` из следующих мест:1. `02-lesson/frontend/.env` (переменные `OPENCODE_API_KEY`, `VITE_OPENCODE_API_KEY`, `GEMINI_API_KEY`)2. Корневой файл `.env` проекта3. Локальный `.env` внутри папки `console-chat/`4. Системные переменные окружения (`process.env.GEMINI_API_KEY`)---## 📊 Архитектурные диаграммыПодробные схемы всех 4 уровней смотрите в файле:👉 **[`docs/architecture.md`](./docs/architecture.md)**
