# Архитектура консольного чата (Console Chat Architecture)Документ описывает 4 уровня работы консольного чат-приложения ([chat.js](file:///E:/react/fullstack-vibecoder/fullstack-vibecoder-bot/chat.js)) и адаптера к модели ([geminiAdapter.js](file:///E:/react/fullstack-vibecoder/fullstack-vibecoder-bot/geminiAdapter.js)).---## Уровень 1. Контекст системы (System Context)Показывает внешние границы приложения: пользователя, Node.js CLI и внешнюю языковую модель Google Gemini.```mermaidflowchart LR    User["👤 Пользователь"]    ChatApp["💻 Node.js CLI Chat App\n(chat.js + geminiAdapter.js)"]    GeminiAPI["☁️ Google Gemini Cloud API\n(gemini-3.5-flash-lite)"]    User -- "Вводит текст сообщения" --> ChatApp    ChatApp -- "HTTPS POST запрос с промптом" --> GeminiAPI    GeminiAPI -- "Сгенерированный ответ" --> ChatApp    ChatApp -- "Выводит текст в консоль" --> User```---## Уровень 2. Среда исполнения и контейнеры (Runtime & Containers)Демонстрирует процессы, потоки ввода-вывода (I/O), сетевые сокеты и облачную инфраструктуру.```mermaidflowchart TD    subgraph OS["🖥️ Операционная система (OS)"]        Terminal["Терминал / Консоль (STDIN / STDOUT)"]    end    subgraph NodeRuntime["⚙️ Среда Node.js Runtime"]        EventLoop["Node.js Event Loop"]        Script["chat.js (Главный процесс)"]        HttpSocket["Сетевой TLS/HTTPS Сокет"]    end    subgraph Cloud["🌐 Google AI Cloud"]        LoadBalancer["Google API Gateway"]        Inference["Кластер инференса LLM"]    end    Terminal -- "Поток ввода (process.stdin)" --> Script    Script -- "Асинхронная задача" --> EventLoop    EventLoop -- "Сетевой запрос" --> HttpSocket    HttpSocket -- "TLS 443 (Интернет)" --> LoadBalancer    LoadBalancer --> Inference    Inference --> LoadBalancer    LoadBalancer -- "Ответ 200 OK" --> HttpSocket    HttpSocket --> EventLoop    EventLoop --> Script    Script -- "Поток вывода (process.stdout)" --> Terminal```---## Уровень 3. Пошаговая последовательность выполнения в коде (Code Execution Sequence)Детальная диаграмма вызовов функций и событий от ввода символов до отображения ответа.```mermaidsequenceDiagram    autonumber    actor User as Пользователь    participant STDIN as process.stdin    participant RL as readline (rl)    participant Chat as chat.js (line listener)    participant Adapter as geminiAdapter.js    participant Fetch as global.fetch    participant Gemini as Google Gemini API    participant STDOUT as process.stdout    User->>STDIN: Вводит текст и нажимает Enter    STDIN->>RL: Передает буфер ввода    RL->>Chat: Вызывает событие 'line' с аргументом line    Chat->>Adapter: Вызов askGemini(line)    Adapter->>Adapter: Подтягивает ключ из .env и формирует JSON тело    Adapter->>Fetch: POST https://generativelanguage.googleapis.com/...    Fetch->>Gemini: HTTP-запрос по TLS    Note over Gemini: Генерация токенов ответа моделью    Gemini-->>Fetch: HTTP 200 OK (JSON с candidates)    Fetch-->>Adapter: Response JSON    Adapter->>Adapter: Извлекает candidates[0].content.parts[0].text    Adapter-->>Chat: Возвращает итоговую строку ответа    Chat->>STDOUT: console.log(ответ)    Chat->>RL: rl.prompt() (отображение символа '> ')    STDOUT-->>User: Отображение текста на экране терминала```
