# Архитектура консольного чата с долговременной памятью диалогаДокумент описывает 4 уровня архитектуры консольного чат-приложения ([chat.js](file:///E:/react/fullstack-vibecoder/fullstack-vibecoder-bot/console-chat/chat.js)), модуля памяти ([memory.js](file:///E:/react/fullstack-vibecoder/fullstack-vibecoder-bot/console-chat/memory.js)) и адаптера к модели ([geminiAdapter.js](file:///E:/react/fullstack-vibecoder/fullstack-vibecoder-bot/console-chat/geminiAdapter.js)).Диалог накапливается и при каждом запросе в LLM отправляется вся история сообщений. Вся переписка синхронно сохраняется на диск в файл `memory.json`.---## Уровень 1. Контекст системы (System Context)```mermaidflowchart LR    User["👤 Пользователь"]    ChatApp["💻 Node.js CLI Chat App с памятью\n(chat.js + memory.js + geminiAdapter.js)"]    GeminiAPI["☁️ Google Gemini Cloud API\n(gemini-3.5-flash-lite)"]    User -- "Вводит сообщения диалога" --> ChatApp    ChatApp -- "HTTPS POST с полной историей переписки" --> GeminiAPI    GeminiAPI -- "Контекстный ответ модели" --> ChatApp    ChatApp -- "Выводит ответ и сохраняет память" --> User```---## Уровень 2. Пошаговая последовательность выполнения в коде (Code Execution Sequence)```mermaidsequenceDiagram    autonumber    actor User as Пользователь    participant STDIN as process.stdin    participant RL as readline (rl)    participant Chat as chat.js (line listener)    participant Memory as memory.js    participant Disk as memory.json (диск)    participant Adapter as geminiAdapter.js    participant Fetch as global.fetch    participant Gemini as Google Gemini API    participant STDOUT as process.stdout    User->>STDIN: Вводит сообщение и нажимает Enter    STDIN->>RL: Передает буфер ввода    RL->>Chat: Событие 'line' с текстом    Chat->>Memory: addUserMessage(line)    Memory->>Disk: Запись на диск (fs.writeFileSync)    Chat->>Memory: getHistory() -> массив contents    Chat->>Adapter: askGemini(history)    Adapter->>Fetch: POST с телом { contents: history }    Fetch->>Gemini: HTTPS POST запрос    Gemini-->>Fetch: HTTP 200 OK    Fetch-->>Adapter: JSON ответ    Adapter-->>Chat: Текстовый ответ модели    Chat->>Memory: addModelResponse(reply)    Memory->>Disk: Запись на диск (fs.writeFileSync)    Chat->>STDOUT: console.log(reply)    Chat->>RL: rl.prompt()    STDOUT-->>User: Отображение текста в терминале```
