# C4 Model: Context Diagram (Level 1)Диаграмма контекста показывает систему в целом и ее взаимодействие с внешними акторами (пользователями) и внешними системами.```mermaidC4Context  title System Context diagram for Currency Telegram Bot  Person(user, "Пользователь", "Пользователь Telegram, отправляющий текстовые запросы")    System(bot, "Currency Bot", "Система для конвертации валют относительно USD")    System_Ext(telegram, "Telegram API", "Платформа Telegram, шлюз для сообщений")  System_Ext(frankfurter, "Frankfurter API", "Провайдер данных с актуальными курсами валют от ЕЦБ")  Rel(user, telegram, "Пишет сообщения", "Telegram App")  Rel(telegram, bot, "Отправляет webhook update", "HTTPS POST")  Rel(bot, telegram, "Отправляет ответы и обновляет UI кнопок", "HTTPS POST")  Rel(bot, frankfurter, "Запрашивает свежие курсы валют (base=USD)", "HTTPS GET")```
