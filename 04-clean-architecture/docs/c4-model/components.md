# C4 Model: Components Diagram (Level 3)Диаграмма компонентов демонстрирует внутреннее устройство нашего контейнера (приложения), показывая, как логические блоки кода взаимодействуют друг с другом.```mermaidC4Component  title Component diagram for Bot Application  Container_Ext(telegram, "Telegram API", "External System")  Container_Ext(frankfurter, "Frankfurter API", "External System")  Container_Boundary(app, "Bot Application (Node.js)") {    Component(webhook, "WebhookController", "Presentation", "Принимает и маршрутизирует входящие POST запросы от Telegram (Сообщения и Инлайн-кнопки)")    Component(usecase, "HandleMessageUseCase", "Application", "Бизнес-логика: парсинг, выполнение математических операций, формирование ответов")    Component(frankfurter_api, "Frankfurter Provider", "Infrastructure", "Адаптер для получения данных от франкфуртского API")    Component(telegram_sender, "Telegram Sender", "Infrastructure", "Адаптер для отправки запросов (сообщений) обратно в Telegram")  }  Rel(telegram, webhook, "POST /webhook/telegram", "HTTPS")  Rel(webhook, usecase, "Вызывает .execute() или .handleCallback()")    Rel(usecase, frankfurter_api, "Вызывает .getLatestRates(currency)")  Rel(usecase, telegram_sender, "Создает/редактирует сообщения, отвечает на callback")    Rel(frankfurter_api, frankfurter, "GET /v1/latest?base=USD", "HTTPS")  Rel(telegram_sender, telegram, "POST /sendMessage, /editMessageText, /answerCallbackQuery", "HTTPS")```
