# C4 Model: Components DiagramВ этом файле представлен улучшенный визуальный код диаграммы (PlantUML), который строго следует вашему референсу: единый блок приложения, компактная структура, никаких вложенных рамок для абстрактных слоев и минимальные текстовые метки.```plantuml@startuml C4_Components!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Component.puml' Убираем визуальный шум и тени, делаем линии строгими (ортогональными)skinparam shadowing falseskinparam linetype orthoskinparam nodesep 60skinparam ranksep 60' 1. Внешние системы (Вынесены за границы бота)' Создаем "входящий" и "исходящий" алиас для Telegram, ' чтобы избежать длинной пересекающей линии через весь экран,' как это показано на вашем текстовом чертеже сверху-вниз.System_Ext(telegram_in, "Telegram API", "Входящие вебхуки")System_Ext(telegram_out, "Telegram API", "Исходящие запросы")System_Ext(frankfurter, "Frankfurter API", "Курсы валют")' 2. Единая граница для всего нашего приложенияContainer_Boundary(bot, "Currency Rate Bot") {        ' Блоки на одном уровне:    Component(app, "Fastify App", "Node.js", "Сервер")    Component(webhook, "Webhook Route", "Route Handler", "POST /webhook/telegram")        ' Центральное ядро    Component(usecase, "Handle Message", "Use Case", "Бизнес-логика")        ' Адаптеры на одном уровне    Component(tg_sender, "Telegram Sender", "Adapter", "API-клиент")    Component(rate_provider, "Rate Provider", "Adapter", "API-клиент")}' Выстраиваем связи и их направления для идеальной сетки:' Telegram -> Fastify -> WebhookRel_R(telegram_in, app, "Webhook POST")Rel_R(app, webhook, "Mounts")' Webhook -> Use CaseRel_D(webhook, usecase, "Handle message")' Use Case -> AdaptersRel_D(usecase, tg_sender, "Send reply")Rel_D(usecase, rate_provider, "Get exchange rate")' Adapters -> External APIsRel_D(tg_sender, telegram_out, "API Call")Rel_D(rate_provider, frankfurter, "API Call")@enduml```<details><summary>Mermaid-версия (Для GitHub)</summary>Если ваш инструмент просмотра markdown требует только Mermaid (например, GitHub), вот эквивалентный
