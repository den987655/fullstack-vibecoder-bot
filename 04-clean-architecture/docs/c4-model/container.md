# C4 Model: Container Diagram (Level 2)Диаграмма контейнеров раскрывает систему в масштабе развертываемых единиц (приложений, баз данных, микросервисов). Для нашего бота это один контейнер приложения Node.js.```mermaidC4Container  title Container diagram for Currency Telegram Bot  Person(user, "Пользователь", "Пользователь Telegram")  System_Ext(telegram, "Telegram API", "Платформа общения")  System_Ext(frankfurter, "Frankfurter API", "API курсов валют")  System_Boundary(c1, "Currency Bot System") {    Container(app, "Бот-приложение", "Node.js, Fastify", "Единый сервис, обрабатывающий вебхуки, бизнес-логику и обращения к API")  }  Rel(user, telegram, "Взаимодействует", "App")  Rel(telegram, app, "Передает входящие сообщения", "JSON/HTTPS")  Rel(app, telegram, "Отправляет ответы и обновляет клавиатуру", "JSON/HTTPS")  Rel(app, frankfurter, "Получает курсы валют (REST)", "JSON/HTTPS")```
